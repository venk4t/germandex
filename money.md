# Money

Set things up in this order.

### 1\. [Open a bank account](https://germandex.com/germany/bank-account)

Free for students; set this up first.

### 2\. [Get health insurance](https://germandex.com/germany/health-insurance)

Mandatory for enrolment; read the option types.

### 3\. [Get liability insurance](https://germandex.com/germany/liability-insurance)

A few euros a month covers expensive accidents.

### 4\. [Get a SIM](https://germandex.com/germany/sim-card)

Prepaid first; contracts later.

### 5\. [Understand SCHUFA](https://germandex.com/germany/schufa)

Germany's credit record, explained.
