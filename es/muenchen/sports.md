# Múnich - Deportes

El [ZHS](https://kurse.zhs-muenchen.de/de) ([Zentraler Hochschulsport München](https://www.zhs-muenchen.de/zhs/faqs/alle-infos-rund-um-die-sportkurse/)) organiza el deporte para todas las universidades de Múnich.

Un gran programa con reserva en la web ZHS. Tarifas reducidas para estudiantes elegibles: comprueba requisitos y precios. Revisa las fechas y reserva pronto.

## Opciones gratis

-   El Englischer Garten: uno de los parques urbanos más grandes del mundo, genial para correr.
-   Las orillas del Isar y el Olympiapark para correr, ir en bici y las tardes de verano.
