# Aix-la-Chapelle - Démarches

Installation universitaire pour votre première semaine

Il ne s’agit pas d’une liste de contrôle d’arrivée complète. L'enregistrement de l'adresse, le statut d'assurance maladie et, le cas échéant, l'autorisation de séjour sont des tâches distinctes.

### 1\. Pour les étudiants [RWTH](https://help.itc.rwth-aachen.de/en/service/rhb2fhkpjhb7/article/ea917d7e1ee048eca31f7a23d04cced5/) : demandez votre BlueCard

Payez les frais semestriels, téléchargez votre photo dans RWTH SelfService et vérifiez votre adresse postale dans RWTHonline. La BlueCard est votre carte d'étudiant et votre carte de paiement Mensa.

Pas arrivée ? Vérifiez montant, photo et adresse postale, puis contactez le point de service [RWTH BlueCard](https://help.itc.rwth-aachen.de/en/service/rhb2fhkpjhb7/article/4ab6340c22ac486cbf2be44352a6fff5/). Ce n'est pas le ticket semestriel.

### 2\. Pour les étudiants de [RWTH](https://www.asta.rwth-aachen.de/en/semesterticket-faq/) : configurez votre messagerie universitaire

Échangez votre coupon ConnectMe et ouvrez votre boîte aux lettres RWTH. Des messages importants concernant l'université et les billets semestriels y arrivent.

Accès impossible ? Vérifiez que vous avez utilisé ConnectMe - l'activation peut prendre 48 h ; coupon manquant : contactez le ServiceDesk informatique.

### 3\. Pour les étudiants de RWTH et FH Aachen : utilisez le Mensa

Utilisez votre BlueCard ou FH Karte pour payer dans les cantines [Studierendenwerk](https://www.studierendenwerk-aachen.de/en/eating-drinking/cashless-payment/bluecard-and-fh-card.html). Le chargement automatique est facultatif ; vous pouvez également recharger aux machines.

Pas de puce de paiement ? Renseignez-vous sur la carte invité Studierendenwerk (dépôt + crédit) et présentez votre carte d'étudiant pour le tarif étudiant.

### 4\. Pour les étudiants de RWTH : activez votre ticket semestriel

Après l'inscription et l'activation de ConnectMe, ASEAG envoie un code de liaison à votre e-mail RWTH. Enregistrez-vous une fois sur naveo avec ce code ; vérifiez qu'un billet valide apparaît avant de voyager.

Code naveo manquant ? Vérifiez inscription, frais, ConnectMe et boîte RWTH, puis écrivez à semesterticket@aseag.de. Code utilisé sans ticket : hallo@naveo.info - ne supprimez pas le compte.

naveo inutilisable ? RWTH AStA explique la demande de ticket physique par carte à puce ; comptez jusqu'à deux semaines, ce n'est pas un ticket provisoire.

-   Le billet Deutschlandsemester couvre les transports locaux et régionaux en deuxième classe, pas ICE/IC/EC. Il est financé par les frais semestriels et non par un billet gratuit.
-   N'embarquez pas sans billet valide. Si votre abonnement semestriel n'est pas prêt, achetez d'abord un autre tarif valide.
-   Les arrêts de bus peuvent avoir plusieurs quais (H1, H2, etc.). Vérifiez la plate-forme pour votre direction.

Pour les étudiants de la FH Aix-la-Chapelle : utilisez les instructions universitaires spécifiques à la FH pour votre FH Karte, votre e-mail et votre ticket semestriel ; les étapes RWTH ci-dessus ne s’appliquent pas.

## Plus qu'une simple configuration universitaire

### Enregistrez votre adresse à Aix-la-Chapelle

Enregistrement de l'adresse : [Ville d'Aix-la-Chapelle](https://serviceportal.aachen.de/suche/-/vr-bis-detail/dienstleistung/4599/show), dans les deux semaines suivant l'emménagement. Titres de séjour : [Bureaux d'immigration de la StädteRegion](https://www.staedteregion-aachen.de/en/navigation/residence-permit). Documents, assurance maladie, statut de résident et lettres officielles : [guide administratif national](https://germandex.com/fr/germany/admin).

Vous pouvez vous enregistrer entièrement [en ligne](https://serviceportal.aachen.de/suche/-/vr-bis-detail/dienstleistung/4599/show) (carte d'identité ou carte eID européenne avec eID activée, son code PIN et un compte BundID gratuit) ou sur place avec un rendez-vous préalable au Bürgerbüro ou dans un Bezirksamt.
