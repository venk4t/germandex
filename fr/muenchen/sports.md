# Munich - Sport

Le [ZHS](https://kurse.zhs-muenchen.de/de) ([Zentraler Hochschulsport München](https://www.zhs-muenchen.de/zhs/faqs/alle-infos-rund-um-die-sportkurse/)) organise le sport pour toutes les universités de Munich.

Un grand programme à réserver sur le site ZHS. Tarifs réduits pour les étudiants éligibles : vérifie les conditions et les prix. Regarde les dates d'inscription et réserve tôt.

## Options gratuites

-   L'Englischer Garten : l'un des plus grands parcs urbains du monde, idéal pour courir.
-   Les berges de l'Isar et l'Olympiapark pour le jogging, le vélo et les soirées d'été.
