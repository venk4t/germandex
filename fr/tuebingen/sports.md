# Tübingen - Sport

## Pour les étudiants de l'Université de Tübingen : Hochschulsport

[Hochschulsport Tübingen](https://uni-tuebingen.de/einrichtungen/zentrale-einrichtungen/hochschulsport/home/) propose plus de 350 cours par semestre. Réservez en ligne sur la [page de réservation](https://buchung.hsp.uni-tuebingen.de/angebote/aktueller_zeitraum/m.html).

La page annonce l'inscription pour le semestre d'hiver 2026/27, les cours de tennis ouvrant aux inscriptions le 23 octobre 2026 à 17 h.

Le bureau du Hochschulsport est au Wilhelmstr. 124.

### Consultez les [dates d'inscription](https://buchung.hsp.uni-tuebingen.de/angebote/aktueller_zeitraum/m.html) actuelles

Les cours populaires peuvent se remplir vite. Les horaires d'inscription varient selon le cours ; consultez la page de réservation avant de régler une alarme.

Sources locales vérifiées le 22 octobre 2026. Consultez les pages liées pour les prix et règles actuels.
