# Bochum - Sport

Le [Hochschulsport Bochum](https://buchung.hochschulsport.ruhr-uni-bochum.de/angebote/aktueller_zeitraum/) est géré par la [Ruhr-Universität](https://hochschulsport-bochum.ruhr-uni-bochum.de/de/faqs-oft-gestellte-fragen).

Inscris-toi en ligne à chaque cours avant de participer. Les cours sont généralement moins chers pour les étudiants éligibles : vérifie les conditions et les prix avant de réserver.

## Options gratuites

-   Le Kemnader See, le lac près du campus. Un parkrun gratuit de 5 km a lieu chaque samedi matin.
