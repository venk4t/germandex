# SCHUFA expliquée

### Comprends la SCHUFA

SCHUFA est le dossier de crédit allemand ; les propriétaires demandent souvent un rapport pour louer. Inutile d'ouvrir des produits supplémentaires pour améliorer ton score : SCHUFA conseille de payer les factures à temps et de garder des finances simples. Un bon historique sur tes comptes existants aide avec le temps. Consulte tes données dans l'application SCHUFA ou demande une copie gratuite à SCHUFA. ([Android](https://play.google.com/store/apps/details?id=com.schufamobileapp) / [iPhone](https://apps.apple.com/de/app/schufa/id6448636299))

SCHUFA propose une copie gratuite de vos données (Datenkopie) sur [schufa.de](https://www.schufa.de/datenkopie). (Source : schufa.de, vérifié le 19 octobre 2026.)
